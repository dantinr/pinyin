Windows x64 中文拼音输入法开发预览版，完全离线使用，默认开启本地学习。

- 8,861 条基础词库记录，支持整词输入、离线整句组词、分段改选和自动加词。
- 新增简拼及全拼混输：nh/nhao/nih → 你好，bj → 北京，zg/zhg → 中国；已学整句也可简拼复用。
- 简拼分段选字保留实际剩余输入，学习仍保存完整读音，全拼和简拼共用个人词条与选择次数。
- 新增中文标点及标点选词：nh, → 你好，支持中文引号、括号、顿号、破折号和省略号；学习不包含标点。
- 英文模式保留英文符号，网址/邮箱及数字场景保留相应英文标点；拼音单引号分隔不受影响。
- 已选长句和自定义词可在下次直接复用，个人选词习惯影响排序。
- 候选支持数字/鼠标选择和翻页，长拼音编辑时光标保持可见。
- 密码/PIN 框直接输入，其余普通及隐私文本框支持中文输入和学习。

下载 `private-pinyin-版本号-windows-x64.zip`，完整解压，双击 `install.cmd` 安装，然后使用 Win+Space 切换输入法。随包包含微软 VC++ x64 离线运行库，无需联网下载依赖。

卸载请使用当前安装目录中的 `uninstall.cmd`。个人词库会保留在 `%LOCALAPPDATA%\PrivatePinyin`。

当前仅支持 x64 桌面应用，安装需要管理员权限。详细使用方法见包内 `README.txt`；校验文件见 ZIP 旁的 `.sha256`。
