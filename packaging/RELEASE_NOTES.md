Windows x64 中文拼音输入法开发预览版，默认离线使用并开启本地学习。

- 0.1.13 修复 chatGPT、openAI 等小写开头、随后输入大写的英文词顺序错乱：未确认的字母保留在同一英文组合框内，支持 Shift、CapsLock、光标编辑、取消及空格/Enter/标点确认；关闭自动英文识别时同样生效，不学习英文原文。

- 修复分段选词只保存整段、遗漏已确认短词的问题；整段上屏后同时保存单独选中的多音节词。历史词库只有“统一后台”等长词时，输入完整拼音 `tongyi` 也能找回“统一”，确认后单独学习。兼容已有词库，无需重新录入长词；新增字音对齐、取消与改选、跨应用和真实 TSF 回归测试。

- 再新增 5,000 个此前未收录的常用词语和短语，覆盖口语、动作、交流、办事、工作、学习和生活等 70 个场景分区；补充 62 条单字读音。基础词库增至 24,093 条记录、19,820 个不同词语和短语，增加多音字及全拼、简拼回归检查。

- 补齐“试试、想想、等等、问问、试一试、帮帮忙”等口语表达，以及“实时、时事、适时”等 shishi 同音词，共 46 个新词；增加全拼、简拼与首选排序回归检查。

- 修复有待重试的学习记录时，写入锁繁忙会阻止读取已保存个人词语的问题；读写分别处理，等待保存时仍刷新候选。主词库补充“命令”（ming ling），无需先学习即可检索。

- 0.1.12 修复个人词库暂时读写失败导致学过的词不出现在候选中的问题：读取失败时保留已加载的词条，保存失败时暂存当前应用的选择并在后续输入时重试，合并其他应用的新增词条；关闭本地学习会丢弃尚未保存的选择。新增重试、并发合并、读取恢复及隐私开关回归测试。

- 0.1.11 新增可选个人词库云同步：配置自有服务 URL 和令牌，每 10 分钟后台双向合并，按日期记录词条变化，支持换设备恢复、立即同步、登录启动、冲突重试与状态显示。默认关闭，仅上传个人词条；提供可部署的同步服务示例。

- 0.1.10 修复英文输入中连字符顺序错乱的问题，如 `user-agent`；覆盖大小写、连续连字符及英文识别与中文标点开关的回归测试。构建版本统一读取根目录 `VERSION` 文件。
- 0.10.0 新增本地输入统计：累计与今日中文输入量、上屏次数、有效输入时间、平均速度及每日记录。
- 新增个人词库今日新增、累计新增和最近 30 天每日增长曲线；按不同字词去重，重复使用及同词增加读音不重复计数，个人词库合并也可计入新词。
- 设置面板右上角显示构建版本号，随发布版本自动更新；面板提供统计与词库管理，学习和中文标点仍可通过右键菜单调整，自动英文识别功能保留。
- 补充 1,296 条四字成语及固定表达与 93 条单字读音。
- 新增 3,650 个计算机和编程词语及 8 条单字读音，涵盖硬件、网络、开发、数据库、部署、安全和人工智能等 38 个主题。
- 新增 5,000 个日常常用词语及 75 条单字读音，覆盖家庭、饮食、购物、交通、健康、交流、工作、学习、休闲等 62 个主题；基础词库共 18,984 条记录，含 14,773 个不同词语和短语。
- 个人数据统一存放在 %USERPROFILE%\PrivatePinyin，修复 MSIX 应用与普通桌面应用的学习词库共享；自动迁移旧目录，保留原件。
- 修复剪映加载旧版微软 C++ 运行库时的输入崩溃；增加旧宿主运行库兼容性验证。
- 统计仅保存日期和汇总数字，不保存输入原文、词语或逐次活动，完全离线。已有个人词库不追溯过去的新增日期。
- 0.9.0 新增个人词库导出与合并：设置窗口选文件或独立 personal JSON CLI，保留词语、完整读音与选择次数，同词同读音取较大次数，重复导入不累加。修改前自动备份，支持并发学习、错误保留原文件与下一轮输入刷新；普通词库可从设置合并到辅词库。
- 0.8.0 新增用户 Agent 词库管理入口：主词库与多个主题辅词库合并，个人学习记录独立。支持 JSON CLI、结构校验、去重导入、逐词编辑、文件启停和备份，下一轮输入自动刷新。
- 修复跨程序本地学习查询：读取完整文件快照，无需获取写入锁，另一应用保存时不会因锁冲突隐藏已发布词语；成功重新读取后恢复学习可用状态。

- 新增自动英文识别（试用，默认开启）：hello world, how are you? 保留英文空格、标点和大小写；支持大写句首和常见缩写形式，英文段不学习。
- 中文模式下首个 Shift+字母保留在组合输入框，与后续字母组成完整英文原文；支持光标编辑、Esc 整词取消、Enter 提交和空格提交并保留空格，关闭自动识别仍可使用。
- 自动英文段显示“英”，Shift 可立即返回拼音；回车、Tab、Esc、方向/定位键及失焦自动退出。自动识别入口已从设置窗口及右键菜单移除，原有关闭标记仍兼容。
- 修复 Hello 按 Enter 确认后无法继续输入空格的问题：Enter 确认首词也进入自动英文段，空闲中文状态不再预先拦截空格。
- 保守识别：小写合法拼音、全拼词条及补全优先，显式中文选词优先；未知英文和歧义词可能仍需手动切换。
- 24,093 条基础词库记录，支持整词输入、离线整句组词、分段改选和自动加词；补充缺失单字“裆”（dang）。
- 新增末尾音节补全：niha → 你好、beijin → 北京、wozaibeijin → 我在北京；支持简拼混输。
- 补全只扩展最后音节，分段改选与编辑保留实际拼写；学习保存完整读音，全拼、简拼与补全共用词条。
- 修复 Shift+字母被当作小写拼音的问题；直接交给应用输入英文大写，单独 Shift 仍切换中英文，拼音途中输入大写保留已有文字且不学习未确认词。
- 新增简拼及全拼混输：nh/nhao/nih → 你好，bj → 北京，zg/zhg → 中国；已学整句也可简拼复用。
- 简拼分段选字保留实际剩余输入，学习仍保存完整读音，全拼和简拼共用个人词条与选择次数。
- 新增语言栏 / 任务栏“中 / 英”状态按钮，点击切换、Shift 同步更新；右键提供设置与个人词库目录入口。
- private_pinyin_settings.exe 提供图形统计与词库管理，兼容原有命令行学习开关。
- 关闭中文标点后仍可用英文符号确认候选：nh, → 你好,。关闭学习保留词库但停用个人词；密码/PIN 继续直接输入。
- 支持中文标点及标点选词：nh, → 你好，支持中文引号、括号、顿号、破折号和省略号；学习不包含标点。
- 英文模式保留英文符号，网址/邮箱及数字场景保留相应英文标点；拼音单引号分隔不受影响。
- 已选长句和自定义词可在下次直接复用，个人选词习惯影响排序。
- 候选支持数字/鼠标选择和翻页，长拼音编辑时光标保持可见。
- 密码/PIN 框直接输入，其余普通及隐私文本框支持中文输入和学习。

下载 `private-pinyin-版本号-windows-x64.zip`，完整解压，双击 `install.cmd` 安装，然后使用 Win+Space 切换输入法。随包包含微软 VC++ x64 离线运行库，无需联网下载依赖。

卸载请使用当前安装目录中的 `uninstall.cmd`。个人词库会保留在 `%USERPROFILE%\PrivatePinyin`。

当前仅支持 x64 桌面应用，安装需要管理员权限。详细使用方法见包内 `README.txt`；校验文件见 ZIP 旁的 `.sha256`。
