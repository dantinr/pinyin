PenBlade · 笔锋输入法：Windows x64 离线安装包

个性化：设置 → 个性化设置，可开启状态图标轮换（默认关闭），或打开个人 ico 目录添加图标。
内置 8 个图标；右侧 P 标识保留，鼠标悬停查看中英文状态。详细规则见 ico/README.md。

默认离线，个人词库由你掌控。
项目展示名称为 PenBlade · 笔锋输入法；Windows 中仍显示“隐私拼音（开发版）”。
程序文件名、注册标识和 PrivatePinyin 数据目录沿用当前实现。

安装
1. 将 ZIP 完整解压到任意目录。不要直接从压缩包内运行程序。
2. 双击 install.cmd，并同意 Windows 管理员权限提示。
3. 安装器将程序复制到 C:\Program Files\PrivatePinyin\版本号，
   必要时安装随包附带的微软 VC++ x64 运行库，再注册输入法；全过程无需联网。
4. 使用 Win+Space 切换到“隐私拼音（开发版）”，重新打开需要输入的应用。
5. 输入 nihao，按空格选“你好”；数字 1–9 选词，PgUp/PgDn 翻页。
   也可用简拼 nh 或混输 nhao/nih；bj 可选“北京”，zhg/zg 可选“中国”。
   简拼支持分段改选、整句组词和本地学习，学习时保存完整读音。
   支持末尾音节补全：niha 可选“你好”，beijin 可选“北京”，wozaibeijin 可选“我在北京”。
   不预测尚未输入的后续音节；补全与全拼、简拼共用完整读音的学习词条。
6. 中文模式下，输入 nh 后按逗号可上屏“你好，”，按 Shift+1 可上屏“你好！”。
   支持中文句号、问号、括号和交替开闭的引号；拼音单引号仍用于分隔音节。
   反斜杠输入顿号，Shift+- 输入破折号，Shift+6 输入省略号。
   英文模式保留英文符号；网址/邮箱以及小数点、时间等场景保留相应英文标点。
7. 语言栏 / 任务栏的“中 / 英”按钮显示当前模式，点击或按 Shift 切换。
   单独按 Shift 切换模式；中文模式下 Shift+字母进入组合输入框，整词保留大小写，组合键不切换模式。
   小写开头后输入大写也保留整词顺序，如 chatGPT、openAI；支持 Shift 和 CapsLock，尚未选定中文分段时生效。
   英文原文可编辑、Esc 整词取消，Enter 提交，空格提交并保留空格；关闭自动识别仍可使用。
   自动英文识别（试用）默认开启：hello 后按空格或 Enter 可继续输入英文句子，保留空格与英文标点。
   Enter 确认首词只提交原文；英文段中再次按 Enter 则退出并交给应用。
   支持 Hello、I am 等大写开头；英文不加入个人词库。you/he/she 等小写歧义词仍优先按拼音处理。
   已收录中文词条的全拼、简拼、混输与末尾补全优先，例如 went 可选“问题”；
   与英文词冲突时可按 Shift 切到英文，或使用 Went 等明确大写开头的英文原文。
   自动英文段显示“英”；Shift、回车、Tab、Esc、方向/定位键或离开输入框后返回拼音。
   未收录英文词、人名或拼写错误可能需要手动切换。
   右键可切换本地学习、中文标点，打开设置和个人词库目录。
   也可直接运行 private_pinyin_settings.exe，查看输入统计和管理个人词库；右上角显示当前版本号。
   关闭中文标点后 nh, 仍可上屏“你好,”。学习与标点设置跨应用、重启保留。

默认开启本地学习。词语、读音和选择次数保存在
%USERPROFILE%\PrivatePinyin\words.user.tsv。
密码/PIN 框直接输入。默认离线，无遥测、逐键日志或完整输入流水；
本地学习会保存已确认词语，也可能保存完整长句，导出文件也包含这些词条。
词库、统计和备份为本地明文，其他有权限的本机程序可以读取。
输入法 DLL 本身不发起网络请求；个人词库云同步需手动开启。
设置窗口点击“云同步…”，填写自己的同步服务地址和可选令牌，勾选启用并保存。
首次立即同步，此后每 10 分钟后台双向合并，按同步日期保留词条记录；登录后自动恢复。
换设备填写相同地址和令牌即可恢复词库。“立即同步”可手动触发，取消勾选并保存可停止。
地址需支持词库同步读写，普通网页或仅下载链接不能上传。部署示例见 tools/sync_server.py，说明见 docs/cloud-sync.md。
只上传个人词语、读音与选择次数，不上传输入统计、按键、基础词库或辅词库。
学习开关可通过安装目录中的 private_pinyin.exe --ime-learning on|off|status|clear 设置。
学习与同步是独立开关；关闭学习不会停止同步，数字统计也继续累计。
关闭同步会移除登录启动项，但保留本地和云端数据。清空本地个人词库不会删除云端词条，
同步开启时可能重新恢复；需要清理全部副本时，先在所有设备关闭同步，再清理本地、备份和服务端文件。
完整规则见 docs/cloud-sync.md。

设置窗口提供“导出个人词库…”和“合并词库…”。导出为 UTF-8 TSV，保留选择次数。
“合并词库…”自动读取当前用户词库，显示确认提示后合并到 %USERPROFILE%\PrivatePinyin\main.tsv。
按词语和读音去重，有新增词条时先备份到同目录 backups；用户词库和选择次数保留。
下一轮拼音输入生效；关闭本地学习或清空个人词库后，已合并的主词库词条仍可使用。
导入其他个人词库或普通权重词库可通过 personal / lexicon CLI 操作，见 docs/personal-dictionaries.md。
下一轮输入刷新；个人词库需开启本地学习后使用。
Agent 可使用 private_pinyin.exe personal help 发现导出、校验与合并命令。
完整规则见 docs/personal-dictionaries.md。

设置面板显示累计与今日中文输入量、输入速度、每日统计和个人词库规模。
个人词库显示今日新增与累计新增；“词库增长曲线”页显示最近 30 天每日新增。
统计从安装此功能后开始，只保存日期及汇总数字，不记录输入原文。
本地文件为 %USERPROFILE%\PrivatePinyin\statistics.tsv；详细口径见 docs/input-statistics.md。
每日新词汇总另存为同目录的 vocabulary-growth.tsv，不记录词语内容。

用户自己的 Agent 可运行 private_pinyin.exe lexicon help 管理词库。
随包基础词库 data/base.tsv 保持只读；用户主词库 main.tsv 由“合并词库…”维护。
主题辅词库存放在
%USERPROFILE%\PrivatePinyin\dictionaries。新增和启停在下一轮输入生效。
完整协议、补词规则与命令示例见 docs/agent-dictionaries.md。

安装完成后，下载的 ZIP 和解压目录可以删除。
安装目录必须保留。每个新版本安装到独立目录，更新不覆盖已加载的旧 DLL。
升级后重新打开应用以加载新版本；旧版本目录可在应用退出后手动删除。

卸载
在当前安装版本的目录内双击 uninstall.cmd。
卸载移除本输入法注册，保留个人词库和共用的微软 VC++ 运行库。
同时关闭本输入法的云同步并移除登录启动项，不删除云端词库。
关闭加载输入法的应用后，可手动删除该版本安装目录。

private_pinyin_demo.exe 是无需系统注册的测试窗口；运行前需已安装随包的 VC++ 运行库。
private_pinyin.exe 是词库查询和本地学习管理工具。
private_pinyin_settings.exe 是无需管理员权限的图形设置窗口。
private_pinyin_sync.exe 仅在开启云同步后后台运行，不阻塞输入；令牌由 Windows 当前用户加密保存。
data\README.md 说明基础词库的来源和覆盖范围。
manifest.json 记录版本、来源提交、运行库版本和文件 SHA-256，用于完整性检查。

当前为开发预览版，仅支持 Windows x64 桌面应用，尚未做代码签名。
系统框架由 Windows 提供；vc_redist.x64.exe 是微软官方运行库安装包。
