# 基础拼音词库

`base.tsv` 是 2026-10-08 整理的基础词库，供本项目的 Windows 中文拼音输入法离线使用。本版由 Codex 在本项目开发过程中生成和整理，保留原来的 99 条演示数据；未导入第三方词表、开源输入法词库或用户输入记录。它是起步词库，尚未经过独立语言专家审校或真实语料词频评估。

本目录随仓库提供的基础词库、主题源文件和文档采用 [MIT License](../LICENSE)。该许可不涉及用户自己输入、学习、导入或同步的个人词库内容。

## 格式与读音

文件使用 UTF-8、LF 换行。每行三列，用实际 TAB 分隔：

```text
手机<TAB>shou ji<TAB>10000
收集<TAB>shou ji<TAB>7000
重庆<TAB>chong qing<TAB>7500
女孩<TAB>nv hai<TAB>7000
```

- 不标声调；音节用单个空格分隔。`ü` 写成 `v`；`ju`、`qu`、`xu`、`yu` 保留正常拼音拼写。
- 按整个词标注读音，例如“银行”是 `yin hang`，“行走”是 `xing zou`。不把单字的全部读音组合成词语读音。
- 本版按书写汉字逐字对应音节；“一会儿”写作 `yi hui er`。这是当前词库的切分约定，尚不提供合并儿化音节的输入方式。
- 同词同读音只保留一条，初始整理时取较大权重；同词不同读音保留。文本相同但声调不同且无调拼音相同的读音不会拆成多个候选。
- 从已标注词语中补充缺少的单字读音，便于单字输入；这些读音仍需随词条一起维护。

## 权重与当前能力

权重是人工规则设定的候选优先级，不是真实词频。常用表达和重点词适当提高权重；领域词、固定短语和补充单字按组赋值。例如 `shouji` 优先显示“手机”，其次是“收集”。同一组大量词条权重相同，现有引擎的并列排序不能代表每个词的真实常用程度。

基础词表未使用个人输入日志或选词记录。新增词语及读音由本项目逐项整理；个别疑难读音参照教育部《重编国语辞典修订本》核对，例如[纂](https://dict.revised.moe.edu.tw/dictView.jsp?ID=9663&la=0&powerMode=0)、[咯血](https://dict.revised.moe.edu.tw/dictView.jsp?ID=66609&la=0&powerMode=0)，没有复制释义、例句或导入第三方词库文件。覆盖检查在本机按 Windows 代码页解码字符范围，不依赖在线服务。

TSF 输入法只读基础词库；默认开启本地学习，将完全确认的词语保存到独立的本地用户词库，不上传，也不写入本基础词表，可通过 `--ime-learning off` 关闭。

引擎优先匹配完整词条，例如 `xiexienindebangzhu` 可以得到“谢谢您的帮助”。未收录的完整句子可通过保留有限路径的搜索组合已有单字和词语，例如 `wozaibeijingshangban` 的首选是“我在北京上班”；也可按拼音前缀逐段改选。支持简拼和全拼混输，例如 `nh / nhao → 你好`、学过整句后可用 `wzbjsb → 我在北京上班` 直接复用，词库仍保存完整音节，无需另建简拼词库。开启本地学习后，完全确认的长句和自定义候选可成为用户词条，后续整体输入，不再设 16 字上限。个人词确认一次即可优先于同拼音的未使用词。整句排名仍基于人工权重、分词惩罚和个人选择次数，没有训练过的语法或上下文模型，可能出现不自然的同音组合。模糊音和纠错仍需后续开发。

## 维护与验证

0.8.0 起可把用户或用户 Agent 整理的主题词语放入用户目录的独立辅词库，无需修改本主词库。文件格式、合并规则、校验和本地 CLI 见 [Agent 词库说明](../docs/agent-dictionaries.md)。自动学习词库继续独立保存。

基础部分可直接编辑 `base.tsv`；三个主题在 `data/themes/*.tsv` 中维护，修改后于仓库根目录执行：

```powershell
python tools/merge_theme_dictionaries.py
```

脚本只依赖 Python 标准库，校验格式、字数与音节数、重复项后，重建 `base.tsv` 中 `BEGIN/END maintained theme dictionaries` 标记之间的内容，并补齐单字读音。不要直接编辑这个自动合并区；标记之外的原有记录及权重保留。重复运行不会累积词条，控制台输出当前统计，便于同步更新本文。

构建时复制 `base.tsv` 到可执行文件和输入法 DLL 所在目录的 `data/base.tsv`；发布包直接携带合并后的基础词库，运行不依赖 Python 或主题源文件。希望在较旧版本中单独使用这些主题，也可通过 [Agent 词库接口](../docs/agent-dictionaries.md) 将源文件作为辅词库导入；新版基础词库已收录时无需重复导入。

修改后运行项目测试：

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

`tests/dictionary_tests.cpp` 对真实基础词库检查加载、规范拼音、字数与音节数对应、重复记录，以及全部 3,755 个 GB2312 一级汉字的单字覆盖。逐条检查每个词所用的单字读音是否可以独立查询，全部记录是否出现在输入法候选范围内，避免有字却因候选上限不可选。

另验证计算机、日常主题、动物、植物、电影的查询样例，覆盖疑难读音、长片名、全拼、简拼和混输，并检查首候选及错误读音排除。确认计算机扩充区至少含 2,000 个不同词语、首批日常扩充区至少含 5,000 个不同词语、第二批常用词扩充区至少含 5,000 个此前未收录的不同词语，并检查 `tingzhi → 停zhi → 停滞` 的分段选择。Windows TSF 测试验证“停滞”整词和“滞”单字实际上屏。结构和候选可达性检查覆盖全部记录，读音和排名正确性仍属于抽查，不能代替语言专家审校或真实语料词频评测。

原来的小词库保留在 `tests/fixtures/base-demo.tsv`，用于核心和命令行测试中需要固定候选数量、排序的场景。实际基础词库由独立的 `pinyin_dictionary` 测试验证；TSF 集成测试读取 DLL 旁的部署词库。
