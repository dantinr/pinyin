# 个人词库导出与合并

右键语言栏或任务栏的“中 / 英”按钮，打开“设置…”，可使用“导出个人词库…”和“合并词库…”。也可直接打开安装目录中的 `private_pinyin_settings.exe`。

## 导出

点击“导出个人词库…”，选择保存位置。导出包含已学习的词语、完整拼音和选择次数，使用 UTF-8 TSV，支持中文文件名。不导出基础词库、辅词库、设置或输入原文。覆盖已有导出文件时，文件选择窗口会提示确认。尚未学习任何词语时可导出空词库。

## 合并

点击“合并词库…”，自动使用当前用户词库 `%USERPROFILE%\PrivatePinyin\words.user.tsv`，无需选文件。确认窗口显示来源、主词库位置、去重与备份规则，默认选择“否”。选择“是”后才执行合并；取消不修改词库。

主词库存放在 `%USERPROFILE%\PrivatePinyin\main.tsv`，包含安装包基础词库与确认合并的词条。按“词语 + 完整读音”去重，不同读音分别保留；已有词条保留排序权重，新增词条使用 12000 的默认权重，不把个人选择次数当作权重。用户词库与选择次数完整保留，本地学习开关不变。

有新增词条时，先在同目录 `backups` 文件夹生成带日期与唯一编号的 `main.*.tsv` 备份，再原子保存主词库。首次合并备份安装包基础词库，以后备份已有主词库。备份失败、词库损坏、写入锁超时或文件替换失败时不覆盖原词库。没有新增记录时不改写主词库，也不创建额外备份。结果窗口显示新增、已存在、总记录数与保存位置。

运行中的输入法在下一轮拼音输入刷新主词库，正在编辑的组合不会中途改变；关闭本地学习后，已确认合并的词语仍可使用。清空个人词库不会删除主词库中的词；需要撤销时可恢复主词库备份或删除 `main.tsv`。主词库损坏时，已运行应用保留最后一次成功加载的内容。主词库位于用户目录，升级和卸载保留；新版本的安装包基础词库也继续参与候选。

导入其他文件仍可通过 CLI：个人词库使用 `personal merge --file "文件.tsv"`，同词同读音的选择次数取较大值；普通词库使用 `lexicon import --name imported --file "文件.tsv"`，合并为辅词库并保留排序权重。命令用法见后文及 [Agent CLI](agent-dictionaries.md)。

## TSV 格式

个人词库第三列为选择次数，普通词库第三列为排序权重。三列均使用实际 TAB 分隔：

```text
# private-pinyin user dictionary v1: text<TAB>pinyin<TAB>selection_count
电脑	dian nao	5
重载	chong zai	2
重载	zhong zai	7
```

文件为 UTF-8，可带 BOM，支持 LF/CRLF 和以 `#` 开头的注释。拼音不带声调，音节用空格分隔，`ü` 用 `v`；拼音会规范化。次数为 1 到 1,000,000,000 的整数。导入文件允许重复行，规范化后取较大次数；当前活动个人词库仍严格拒绝重复行，避免静默覆盖手工损坏的数据。空文件表示没有新增记录。

导出的个人词库带上述类型标记。系统能拒绝把本项目带主词库或辅词库标记的文件当成个人选择次数；没有类型注释的 TSV 以用户所选文件类型为准，手工整理时应保留正确标记。

## 命令行与 Agent

`personal` 是显式访问个人词库的独立入口；原有 `lexicon` 入口仍只管理主词库与辅词库。输出一行 UTF-8 JSON，`schema=1`，成功退出码 0、失败 1。可以先运行 `personal help` 发现命令。

```powershell
.\private_pinyin.exe personal export --file "D:\备份\个人词库.tsv"
.\private_pinyin.exe personal validate --file "D:\备份\个人词库.tsv"
.\private_pinyin.exe personal merge --file "D:\备份\另一份个人词库.tsv"
```

`export` 默认拒绝覆盖已有文件；明确覆盖时加 `--overwrite`。禁止导出覆盖活动个人词库自身，包括指向同一文件的链接。`export` 和 `merge` 可用 `--user "D:\测试\words.user.tsv"` 指定独立个人词库；不指定则使用当前 Windows 用户的默认路径。`validate` 只检查源文件，不访问活动个人词库。

合并结果包含 `imported`（导入去重后条数）、`added`、`updated`、`unchanged`、`total` 和 `backup`；没有备份时 `backup` 为空字符串。导出结果包含 `entries` 和保存 `path`；校验结果包含 `records`、`entries`、`duplicates`。

导出读取完整已发布快照，不锁住其他应用的学习；合并持有短暂写入锁，重新读取最新记录后保存，避免丢失其他应用刚学习的词语。不会联网或自动上传导出文件。

输入法遇到写入锁忙时，保留待保存的选择并在后续输入中重试；即使尚有待保存记录，也继续读取已发布的个人词库，使其他应用或同步程序刚保存的词语可供选择。重复刷新不会重复累加待保存次数。候选栏显示“学习暂不可用”时表示仍有读写失败，已加载的候选可继续使用。

一段拼音分次选词时，整段成功上屏后会同时记住完整短语与单独确认的多音节词。例如输入 `tongyihoutai`，先选择“统一”再选择“后台”，会保存“统一后台”“统一”和“后台”；每个词在一次上屏中只计一次。取消、回退改选或原样 Enter 提交不会学习被放弃的词。

历史记录只有长词时，完整拼音查询也会找回其中的连续短词。例如已保存“统一后台”，输入 `tongyi` 可选“统一”。这种候选只从汉字与音节逐字对应的记录中提取，至少两个字，不对英文混排、缩写扩展或字音数量不一致的词猜测读音，也不覆盖词库已有的明确读音。完整词条优先于这些候选；实际确认短词后才将它单独保存、参与学习排序和同步。仅查询不会批量增加子词或虚构选择次数，关闭本地学习时不使用这些历史记录。
