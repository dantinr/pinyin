# 本地输入统计

打开语言栏或任务栏按钮的“设置…”，或者运行 `private_pinyin_settings.exe`，即可查看：

- 累计和今日成功确认的中文输入字数与上屏次数。
- 累计平均速度、今日平均速度，单位为字/分钟。
- 按日期倒序排列的字数、上屏次数、有效输入时间、平均速度和个人词库新增词汇；较早日期可滚动查看。
- 当前个人词库的不同字词数、读音记录数和选择次数合计。
- 个人词库今日新增、开始统计后累计新增，以及“词库增长曲线”页的最近 30 天每日新增折线。

面板每 3 秒自动刷新，也提供“刷新”按钮。词库导出、合并和目录入口继续保留。本地学习与中文标点的现有行为保留，面板已移除这两项开关；仍可通过右键菜单调整。

## 统计口径

从安装本功能并重新打开使用输入法的应用后开始记录。仅统计 TSF 成功提交的完整中文候选，包括空格、数字选词、鼠标选词、整句、分段完成和标点确认。只计算其中的汉字，标点、空格、英文和数字不计入字数。每次完整确认记作一次上屏，分段尚未完成时不重复计数。

取消组合、按 Enter 提交拼音原文、失焦保留未确认文本、纯英文原文、直接英文模式、密码/PIN 框及按键探测不产生统计。已确认文字后来被删除或撤销，不扣除输入次数或字数。学习开关只影响个人词库，独立的数字统计继续累计。

有效时间按输入法实际处理的组合编辑及确认操作之间的单调时钟间隔累计。停顿达到 30 秒的整个间隔不计入，取消或失焦则丢弃尚未确认组合的时间。连续确认之间的短间隔参与下一次确认的速度计算；鼠标选词的等待也按同一规则计算。这是输入速度估计，不是应用前台时长或键盘测速。

速度 = 成功确认的汉字数 × 60,000 ÷ 有效毫秒数。有效时间不足 1 秒时显示“待积累”；较短样本的速度容易波动。跨午夜的一个组合归到确认上屏当天，时间也随该次确认计入。

个人词库指标来自现有 `words.user.tsv`，同字词不同读音分别计为读音记录；选择次数可能包含旧版记录和合并词库数据。因此它与新功能累计的上屏次数不同，不能用来推算过去的每日输入量或速度。

## 个人词库每日新增与增长曲线

每次成功保存个人词库时，比较本次与上次已保存的不同字词集合，将新出现的字词计入本地日期。判断在个人词库写入锁内完成，多应用同时学习同一词只计一次；重复选词、同词增加读音或增加选择次数均不计入。分段输入仅在完整确认并成功学习后计数。

通过设置窗口或 CLI 合并个人词库时，新出现的字词也计入当天；再次合并同一文件不重复计数。辅词库导入及旧目录的自动迁移不计入。已有词库没有新增日期，因此不会追溯过去或把历史记录全部计为今天的新词。删除词语不扣减历史新增，删除后重新加入属于新的添加；“累计新增”是添加量，不等于当前词库规模。

“每日统计”中的“新增词汇”列显示该日新增数；“词库增长曲线”展示截至今天最近 30 个自然日的每日新增，纵轴为字词数，横轴为日期。开始统计后没有新增的日期补 0，开始统计前留空、表格显示“—”。今日新增是当天的部分数据。停用学习后输入量仍正常累计，但没有学习产生的新词。

统计只覆盖更新后的输入法或词库管理工具成功保存的操作。Agent 直接编辑 TSV 没有可确认的添加时间，不计入每日新增；建议通过 `personal merge` 合并，以便记录新增数量。

独立文件为 `%USERPROFILE%\PrivatePinyin\vocabulary-growth.tsv`，UTF-8、实际 TAB 分隔，格式如下：

```text
# private-pinyin vocabulary growth v1: date<TAB>new_words
# tracking-start: 2026-10-12
2026-10-12<TAB>8
2026-10-14<TAB>3
```

它仅保存统计开始日期和各日新增数量，不记录词语或逐次活动。新词成功写入后再以文件锁和原子替换保存汇总。词库与增长文件属于两个独立发布：若中间进程崩溃，或增长文件损坏、不可写、长期被锁定，该次增长可能漏计；统计错误不阻止输入和学习，不把重复选词作为补记。损坏或未知版本的增长文件保留原件，面板提示读取失败。

## 数据与可靠性

固定文件为 `%USERPROFILE%\PrivatePinyin\statistics.tsv`，例如 `C:\Users\用户名\PrivatePinyin\statistics.tsv`。所有应用共用此文件，使用 UTF-8、实际 TAB 分隔、LF 换行：

```text
# private-pinyin input statistics v1: date<TAB>characters<TAB>commits<TAB>active_ms
2026-10-12<TAB>120<TAB>35<TAB>60000
```

上述行表示该日确认 120 个汉字、35 次上屏，有效时间 60 秒，平均速度 120 字/分钟。日期按电脑当前本地日期分组；计时使用单调时钟，不受调整系统时间影响。文件只含日期和汇总数字，不包含输入原文、拼音、词语、按键序列、应用名称或逐次输入时间戳，也不上传。

成功确认后以文件锁保护读、合并和原子发布，避免不同应用同时输入覆盖彼此的计数。读取使用完整已发布快照，不与写入锁冲突。存储繁忙或失败时不阻止输入，只在当前服务内保留尚未保存的数字，后续确认或停用时重试；若一直无法保存且应用退出或崩溃，未保存部分可能丢失。损坏或不支持的统计文件不会被空数据覆盖，面板显示读取失败，可修复后刷新。个人词库独立于统计文件。
