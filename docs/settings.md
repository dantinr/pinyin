# 中英文状态与本地设置

设置窗口中的“云同步…”可配置个人词库同步地址、可选令牌和开关，查看同步状态及最近成功时间。启用后立即双向合并，每 10 分钟后台同步，关闭设置窗口后继续运行，Windows 登录后恢复。点击“立即同步”会保存当前表单并请求立即同步；取消勾选后点击“保存同步设置”停止后台同步并移除登录启动项。默认关闭。地址需要可读写的词库同步服务，见 [云同步设置与部署](cloud-sync.md)。

当前版本为 0.1.15，设置面板右上角显示当前构建的版本号。切换到隐私拼音后，Windows 语言栏或任务栏输入模式位置显示“中 / 英”。点击按钮或单独按 Shift 切换，两种操作同步更新图标、文字和键盘行为。中英文模式属于当前应用会话，新激活的输入法默认中文；学习和标点开关是所有应用共享的持久化设置。

右键按钮（或点击语言栏下拉箭头）可切换“本地学习”“中文标点”，打开“设置…”或个人词库目录。也可直接运行安装目录中的 `private_pinyin_settings.exe`；它无需管理员权限，不依赖目标应用窗口。设置面板显示中文输入统计和个人词库规模，并提供词库管理入口；本地学习、中文标点和自动英文识别的开关已从面板移除，相应功能保留。自动英文识别开关也已从右键菜单移除。

## 个性化设置

“个性化设置…”分为“图标”和“候选窗”两个标签页，默认打开“图标”。切换标签页不会修改或重置已保存的设置。

候选窗配色在“候选窗”标签页调整：点击“候选窗背景…”更改整个候选框的底色，点击“选中行背景…”更改当前候选行的高亮色。系统颜色选择器确认后自动保存，窗口内显示预览，文字自动选用对比度较高的黑色或白色；取消选色不修改设置。“恢复系统配色”可恢复默认底色与高亮色，不影响图标轮换等其他设置。

更改在下一次输入或候选窗刷新时生效，无需重开应用；前提是应用已加载支持此功能的新版 DLL。Windows 高对比度模式下优先使用系统配色，退出后恢复自定义色。颜色仅保存在本机，不参与个人词库云同步。

在“图标”标签页可开启“切回输入法时自动轮换图标”（默认关闭）。开启后依次轮换任务栏左侧状态图标，右侧 P 品牌标识保持不变；鼠标悬停仍显示当前中英文状态，点击和 Shift 的切换行为保留。关闭后恢复“中 / 英”。更改在切回应用或下一次按键时刷新。

内置 13 个透明背景的单色图标（含美国队长、绿巨人、蜘蛛侠、蚁人、火箭浣熊主题），也可点击“打开图标目录”，将自定义 ICO 放入 `%USERPROFILE%\PrivatePinyin\ico`。按文件名顺序与内置图标轮换，同名文件覆盖内置版本；下次输入法激活时读取更新。普通输入、Shift 切换中英文和窗口焦点通知不会推进轮换；新应用首次激活输入法也会选下一个图标。损坏图标跳过，读取失败不阻止输入。目录规则、主题适配与状态文件见 [图标说明](../ico/README.md)。

## 输入统计

面板显示累计与今日输入字数、上屏次数、平均输入速度及每日记录，每 3 秒刷新，也可点击“刷新”。每日表格增加“新增词汇”列，切到“词库增长曲线”页可查看最近 30 天每日新增折线。个人词库同时显示不同字词数、读音记录数、选择次数合计、今日新增和开始统计后累计新增。统计从更新后开始，多个应用共用同一份本地记录；不从已有词库反推过去的新增日期、输入量或速度。统计口径、有效时间和数据格式见[输入统计说明](input-statistics.md)。

## 个人词库导出与合并

设置窗口提供“导出个人词库…”和“合并词库…”。导出保留词语、完整读音与选择次数。点击“合并词库…”会自动读取当前用户词库，先显示来源、主词库位置和合并规则，选择“是”后才合并到 `%USERPROFILE%\PrivatePinyin\main.tsv`；默认选择“否”，取消不修改文件。有新增词条时先备份主词库，按词语与完整读音去重，保留用户词库和选择次数。合并结果显示新增、已存在、总记录数及备份位置，下一轮输入刷新，关闭本地学习时也可使用。导入其他个人词库或普通 TSV 仍可通过 CLI 操作。格式、备份与 CLI 见 [个人词库说明](personal-dictionaries.md)。

## 开关行为

- 本地学习默认开启。关闭后不使用或新增个人词，不删除已有词库；重新开启可继续使用。它和原有 `private_pinyin.exe --ime-learning on|off` 命令共用同一开关。
- 中文标点默认开启。关闭后输出英文符号；输入拼音时仍可用标点确认当前候选，例如 `nh, → 你好,`。空闲英文符号直接交给应用；拼音单引号分隔、网址、数字和密码/PIN 行为保持原有规则。
- 自动英文识别（试用）默认开启。常见英文词后按空格、Enter 或标点可进入临时英文段，例如 `hello world, how are you?`，空格和标点按英文处理；大写开头 `Hello`、`I am ...` 也可识别。Enter 确认首词时只提交原文，随后可继续输入空格和英文；英文段中再次按 Enter 则退出并交给应用。小写 `you/he/she/can` 等合法拼音及已收录词条的全拼、简拼、混输和末尾补全匹配优先，例如 `went` 可按空格选“问题”，不会自动作为英文提交。与英文词冲突时可按 Shift 切到英文，或明确使用大写开头的 `Went`；未知英文词、拼写错误或人名不保证识别。
- 中文模式下，Shift+字母与后续字母、数字和单引号一起保留在组合输入框，显示“英文”提示。尚未选定中文分段时，小写开头后输入大写会将整段转为英文原文组合，例如 `chatGPT`、`openAI`，Shift 与 CapsLock 均保留输入顺序，二者同时使用按实际大小写处理。可退格、移动光标，Esc 取消整个词，Enter 原样提交，空格提交并保留空格，标点使用英文符号。关闭自动英文识别后仍支持这种组合输入，但提交后保持中文模式；英文原文不参与本地学习。
- 自动英文段显示“英”，提示中说明“自动识别”。单独 Shift 或点击模式按钮返回拼音；回车、Tab、Esc、方向/定位键、离开输入框或关闭自动识别也结束英文段，按键本身仍交给应用。数字/鼠标选词、候选导航及已选中文分段优先。网址/邮箱等特殊输入范围沿用原有规则。
- 右键菜单修改开关后自动保存。已运行的输入法在下一次按键或切回应用时刷新设置，关闭学习也会移除尚未确认候选中的个人词；已经选定的分段文本会保留。

设置与个人词库位于 `%USERPROFILE%\PrivatePinyin`。学习关闭标记为 `words.user.tsv.ime-learning.disabled`，标点关闭标记为 `words.user.tsv.punctuation.disabled`，自动英文关闭标记为 `words.user.tsv.automatic-english.disabled`；没有标记即默认开启。每个开关独立保存，修改其中一项不会覆盖另一应用的其他设置。读取设置不创建词库。英文识别只临时读取光标前相邻 ASCII 单词并沿用网址上下文判断，不保存英文句子、按键或应用上下文，英文段不加入个人词库。

## 已安装开发版本的更新

用户及用户自己的 Agent 可以通过本地 CLI 管理多个主题辅词库。默认目录为 `%USERPROFILE%\PrivatePinyin\dictionaries`，它们独立于自动学习开关和个人词库。接口、补词规则及下一轮输入刷新的行为见 [Agent 词库说明](agent-dictionaries.md)。

旧 AppData 目录及 MSIX 应用私有副本自动迁移到新的共享目录，旧文件保留。更新后重新打开使用输入法的应用，详见[存储与迁移说明](user-data.md)。

0.5.0 新增了任务栏支持的 TSF 类别。已有 0.4.0 或更早版本的开发注册，需要在更新 DLL 后重新运行注册脚本一次；发行包的 `install.cmd` 会自动完成。不要仅替换 DLL 后就假定任务栏已经启用新入口。

在**管理员身份的 64 位 PowerShell** 中运行以下命令，可同时避开当前终端的脚本执行策略限制：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\codex_projects\private-pinyin\scripts\register-ime.ps1" -DllPath "D:\codex_projects\private-pinyin\build\Release\private_pinyin_ime.dll"
```

重新打开需要输入的应用并切换到隐私拼音。DLL 同目录需保留 `data\base.tsv` 和 `private_pinyin_settings.exe`。图标的显示位置受 Windows 语言栏配置影响；即使图标被系统隐藏，也可以直接打开设置程序。

实现使用微软的 [语言栏接口](https://learn.microsoft.com/en-us/windows/win32/tsf/language-bar) 和 [任务栏支持类别](https://learn.microsoft.com/en-us/windows/win32/tsf/predefined-category-values)，没有独立常驻托盘进程。
