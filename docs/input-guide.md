# 输入指南

项目展示名称为 PenBlade · 笔锋输入法；Windows 输入法选择器中的实际名称仍为“隐私拼音（开发版）”。安装步骤见 [README](../README.md#快速开始)。

## 基本操作

| 操作 | 按键或入口 |
| --- | --- |
| 切换到本输入法 | Win + Space，选择“隐私拼音（开发版）” |
| 确认高亮中文候选 | 空格，或用数字 1–9 / 鼠标选择 |
| 选择与翻页 | 上下方向键选择，PgUp / PgDn 翻页 |
| 编辑拼音 | 左右方向键、Home / End、Backspace / Delete |
| 取消组合 | Esc |
| 提交拼音原文 | Enter，不作为中文词语学习 |
| 切换中英文 | 单独按 Shift，或点击语言栏 / 任务栏的“中 / 英” |
| 打开设置 | 右键“中 / 英”→“设置…”，或运行安装目录的 `private_pinyin_settings.exe` |

输入法不改变系统默认输入法。密码 / PIN 框直接输入，不进行转换或学习；普通隐私文本框仍可正常输入并学习。失焦时保留未完成组合的拼音原文并结束组合，不学习未完成的文本。

数字 1–9 在当前页有对应候选时用于选词。没有对应候选的数字（包括 0）保留在当前可编辑文本中，按原顺序输入，例如 `v2`、`v2ray2026`；支持主键盘和数字小键盘。进入这种原文组合后可继续编辑，Enter 原样确认，空格确认并保留空格，Esc 整段取消，不作为中文词语学习。没有组合文本时，数字仍直接交给应用。

## 全拼、简拼与补全

- `nihao`、`nh`、`nhao`、`nih` 都可以候选“你好”；全拼和简拼可以在任意音节混用。
- `zh/ch/sh` 同时支持两字母声母和 `z/c/s` 首字母，例如 `zg` / `zhg` 可选“中国”，`cq` / `chq` 可选“重庆”。零声母音节也使用首字母。
- `niha` 可补全为“你好”，`beijin` 可补全为“北京”。只补最后一个已输入音节，不预测后续音节或纠正中间拼写。
- 输入不带声调，`ü` 可用 `v` 表示。`xian` 保留“先 / 西安”等切分歧义；`xi'an` 用单引号明确音节边界。

候选顺序受拼写匹配程度、词库权重和本地选择次数影响。完整拼写通常优先于缩写或补全，不能保证任意输入的首选都正确。学习保存的是完整读音，因此全拼、简拼和补全可以复用同一条个人记录。

## 整句与分段改选

`wozaibeijingshangban` 可以离线组合出“我在北京上班”。若整句候选不合适，可以先选择正确的一段，再为剩余拼音继续选字或选词；全部完成并成功上屏后才学习。

本地学习保存完整确认短语，也保留其中明确选择的多音节词。例如一轮输入中依次选择“统一”和“后台”，成功上屏后可以复用“统一后台”“统一”和“后台”。分两次独立上屏的单字不会自动合成新词。长句可以保存，整句内部未明确选定的子词不会全部自动写入个人词库。详见[个人词库说明](personal-dictionaries.md)。

## 中英文与标点

中文模式默认使用中文标点，例如 `nh,` 可确认候选“你好”并输入“，”。拼音单引号仍用于音节分隔；网址、邮箱、小数点等保留相应英文符号。右键“中 / 英”可以关闭中文标点。

中文模式下 Shift+字母进入可编辑的英文原文组合；尚未选定中文分段时，`chatGPT`、`openAI` 等中途出现大写的输入也保留整词顺序。支持 Shift 和 CapsLock；Esc 取消，Enter 原样提交，空格提交并保留空格，英文原文不进入个人学习词库。

自动英文识别目前为默认开启的试用功能：常见英文词后按空格、Enter 或标点可以进入临时英文段，例如 `hello world, how are you?`。小写合法拼音和已收录词条的全拼、简拼、混输及末尾补全匹配优先，例如 `went` 仍可用空格选“问题”，不会因为它也是英文单词就自动切换。想输入英文 `went` 时，可按 Shift 切到英文或明确使用大写开头的 `Went`。未知单词、人名或拼写错误不保证识别。完整规则及设置入口见[设置说明](settings.md)。

## 命令行调试

在安装目录打开 PowerShell，或在仓库根目录把下列程序路径替换为 `build\Release\private_pinyin.exe`：

```powershell
.\private_pinyin.exe --query nihao
.\private_pinyin.exe --sentence wozaibeijingshangban
.\private_pinyin.exe lexicon help
.\private_pinyin.exe personal help
```

`--query` 查询完整词条，`--sentence` 查询组合整句；二者只使用指定或随程序部署的基础词库，不读取个人词库或主题辅词库，即使传入 `--learn` 也不学习。它们适合验证基础候选，不能用来判断个人词库是否已加载。主题词库预览使用 `lexicon query`，范围见 [Agent 接口](agent-dictionaries.md)。

不带参数进入交互模式，输入拼音查询、输入候选编号确认。CLI 交互默认不学习；显式加 `--learn` 才保存选择，`--user 路径` 可指定独立个人文件。交互命令 `/add yin'si'shu'ru'fa 隐私输入法` 可保存自造词，`/clear` 清空该个人词库，二者均要求 `--learn`；`/quit` 退出。该模式的开关与系统输入法默认开启的学习开关独立。

`--learn` 交互会话期间会占用个人词库写入锁，其他应用仍能读取已有词条，但新学习需等锁释放后重试。调试建议使用独立 `--user` 文件，避免影响日常词库。清空个人数据前请先了解[同步恢复规则](cloud-sync.md#合并与日期)。
