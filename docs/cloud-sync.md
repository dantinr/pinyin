# 个人词库云同步

云同步默认关闭。打开 `private_pinyin_settings.exe`，点击“云同步…”，填写同步地址和服务要求的令牌，勾选“启用双向同步（每 10 分钟）”，点击“保存同步设置”。首次立即同步，此后每 10 分钟同步一次；“立即同步”保存表单并请求新一轮同步。关闭窗口后后台继续运行，Windows 登录后自动恢复。取消勾选并保存可停止同步和登录启动。启用仅作用于当前 Windows 用户，不需要管理员权限。

换设备安装程序，在设置中填写相同地址和令牌并启用，即可将云端词库合并到本地。现有输入法下一轮输入读取更新后的个人词库，无需重启应用或重新注册 DLL；已关闭本地学习时，词库仍可同步保存，但不会用于候选排序。

## 同步地址

地址必须是支持 GET、条件 PUT 和强 ETag 的读写文件地址，例如 `https://sync.example.com/dictionary.tsv`。普通网页、分享页、只读下载链接、仅支持 POST 的 API 或没有条件写入能力的网盘不能直接作为同步地址。可使用下面的服务示例，或实现相同协议；WebDAV 服务需实际支持条件创建和条件更新。每个人使用独立地址或独立令牌；其他设备使用同一份云端文件。

令牌可选，设置后通过 `Authorization: Bearer ...` 发送。令牌在本机通过 Windows 当前用户的 DPAPI 加密保存，不随词库上传。客户端保留 TLS 证书校验，不跟随重定向，也不把令牌发送给重定向后的地址。公网部署使用 HTTPS 和访问控制；HTTP 仅适合受信任的本地测试环境。

## 运行示例服务

示例仅依赖 Python 3 标准库，Windows 和 Linux 均可运行。在服务端将环境变量 `PRIVATE_PINYIN_SYNC_TOKEN` 设置为自己生成的长随机令牌，然后启动：

```powershell
python tools/sync_server.py --host 127.0.0.1 --port 8765 --directory C:\pinyin-sync-data
```

同机测试地址为 `http://127.0.0.1:8765/dictionary.tsv`，设置中填写相同令牌。`dictionary.tsv` 首次同步时自动创建，重启服务仍使用该数据目录。不同用户可使用不同文件名，例如 `/alice.tsv`；同一服务进程的令牌对它管理的所有文件有效，严格的多用户隔离应部署独立服务或在反向代理中按路径授权。

跨设备使用时，在服务器上持续运行该进程，使用自己的域名和 HTTPS 反向代理，把同步地址转发到此服务。不要把本机的 `127.0.0.1` 地址填到另一台设备；它表示设备自身。也可以用 `--host 0.0.0.0` 在受控网络监听，此时服务要求设置令牌。

服务以原子替换持久保存文件，通过 ETag 拒绝旧快照覆盖，默认不记录 URL、请求体或令牌。示例不提供用户注册、令牌轮换后台或域名证书管理。

## 合并与日期

每轮同步先读取云端，再将本地新增词语或较高选择次数加入当天记录，条件写回后合并到本地。相同词语、相同完整读音的次数取较大值，不相加；不同读音保留。重复同步不会重复新增、增加次数或为没有变化的日期添加记录。

云端 UTF-8 TSV 示例，每条记录有四列，用 TAB 分隔：

```text
# private-pinyin sync v1: date<TAB>text<TAB>pinyin<TAB>selection_count
2026-10-15\t你好\tni hao\t3
2026-10-16\t你好\tni hao\t5
2026-10-16\t北京\tbei jing\t1
```

代码块中 `\t` 表示 TAB。客户端合并所有日期，恢复每个词语和读音的最新最大次数。日期是词条变更首次成功同步时的本机日期，不是输入原文日志；离线积累的变更记到重新联网同步当天，不反推历史输入日期。既有日期记录不会因后续次数增加而移除。同一天同词同读音保留较大次数。

这是一种增量合并，没有跨设备删除或次数降低：清空本地词库后，只要同步仍开启，云端记录会在下一次同步恢复。需要清空全部设备时，先在所有设备关闭同步，再分别清理词库和服务端文件。首次使用可能把已有个人词库全部上传，此后只为新增或次数变化的词条添加日期记录；HTTP PUT 发送完整的合并档案，单份档案上限 32 MiB。

## 失败、冲突与本地数据

断网、认证失败、格式损坏或服务错误会显示“同步失败”，并保留最近成功时间，后台等待下一轮，也可手动重试。本地词库不会因空响应、HTML 错误页面或坏数据被清空。若另一设备先完成写入，客户端重新下载并合并，最多重试四轮；条件写入失败不会强行覆盖。

网络传输不持有个人词库写入锁，期间新学习的词语会保留，并在下一轮上传。下载合并有变化且本地已有文件时，先保存在 `backups` 的原件，再进行原子替换。本地文件锁忙或磁盘错误也会保留原件。服务拒绝条件写入、没有强 ETag、只读或跳转到登录网页时会报错，需要调整同步服务，而不是关闭校验。

后台程序是 `private_pinyin_sync.exe`，不会加载到正在输入的应用中。启用时创建当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PrivatePinyinSync` 启动项，关闭同步或卸载时移除。升级后打开新版本的“云同步…”窗口，会更新后台程序的登录启动路径。仅上传个人词语、完整读音和选择次数，不上传设置、令牌、基础词库、辅词库、统计或按键记录。关闭本地学习和关闭云同步是两个独立开关。

本地状态和配置文件说明见 [用户数据](user-data.md)。没有云同步需求时无需部署服务，保持默认关闭即可。
