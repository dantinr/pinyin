# 状态图标

内置 8 个本项目绘制的图标：笔尖、山峰、叶片、星芒、书本、波纹、菱形、竹叶。每个 ICO 包含 16、20、24、32、40、48 像素的透明背景图案。

在 **设置 → 个性化设置 → 切回输入法时自动轮换图标** 中开启（默认关闭）。轮换的是任务栏左侧原来的“中 / 英”状态图标；右侧“P”品牌图标保持不变。鼠标悬停可查看实际中英文模式，点击或 Shift 切换中英文的行为不变。

用户自己的图标放在 `%USERPROFILE%\PrivatePinyin\ico`，可以在个性化设置里点击“打开图标目录”。这里只读取顶层 `.ico` 文件，按文件名排序，与内置图标一起轮换；同名文件覆盖内置版本。不读取子目录、DLL 或 EXE。新增、删除或替换文件后，下次切回输入法生效，不必重新编译。

建议使用透明背景、轮廓清楚的图标；显示时转换为单色轮廓，由 Windows 适配任务栏主题。损坏文件会跳过；目录不可读、状态文件被占用或没有有效图标时，保留当前图标或回退为“中 / 英”，不影响输入。

轮换在输入法激活时进行；普通按键、中英文切换和窗口焦点通知不会前进。Windows 新建应用的输入法实例也属于一次激活。所有应用通过个人数据目录的 `icon-rotation.cursor` 共享上次选择；该文件只保存图标文件名，不包含输入内容。开关文件为 `words.user.tsv.icon-rotation.enabled`，关闭后恢复“中 / 英”，不删除任何图标。

开发者可用 `python tools/generate_icons.py` 重新生成内置 ICO（需要 Pillow）；用户运行输入法无需 Python。新增内置文件时将 ICO 提交到此目录，构建和发布脚本会自动携带。
